Почему не стандартный XGBoost / CatBoost?

Табличный бустинг сваливает все признаки в одну кучу, упуская динамическую кросс-модальную модуляцию. Cross-Attention точно определяет: является ли ночной вход в ДБО индикатором тревоги по кредиту или безобидной проверкой баланса, сопоставляя его с финансовым сальдо.

Multi-Task Learning (MTL) Loss

Loss = BCE(P_pred, y_default) + 0.02 * Huber(Days_pred, Days_true)

Матрица Cross-Attention как источник XAI

Вместо медленного и приближенного SHAP, архитектура RiskTwin извлекает точные веса внимания непосредственно из слоя Multi-Head Attention:

A[i, j] = Softmax( Q_i * K_j^T / sqrt(d) )

Каждое срабатывание риск-триггера сопровождается списком ключевых драйверов с переводом на понятный человеку язык (Human-readable explanation).

⚡ PRESCRIPTIVE AI: OR-TOOLS

Математический синтез оптимальной реструктуризации

Смешанно-целочисленное линейное программирование (MILP) на солвере SCIP за 12 миллисекунд

Целевая функция максимизации чистой стоимости (NPV)
max NPV = Σ [ CF_m / (1 + r_wacc)^m ] * (1 - P_def(load)) - LGD * P_def * Balance
Жесткие регуляторные ограничения (Constraints):
  • Лимит АРРФР: Платеж ≤ 50% от подтвержденного дохода (КДН ≤ 0.50).
  • Бюджет клиента: Новый платеж строго меньше свободного остатка (Free Cashflow).
  • Срок пролонгации: Не более +24 месяцев к действующему договору.
3 сценария, синтезируемых для клиента
1. Сценарий «Пролонгация срока»

Увеличение срока на 12–18 мес. Снижение платежа на 35%. Клиент восстанавливает комфортный ритм жизни.

2. Сценарий «Кредитные каникулы»

Пауза по платежам на 2–3 месяца при подтвержденном временном шоке (смена работы / больничный).

3. Сценарий «Грейс по основному долгу»

Выплата только процентов в течение 3–6 месяцев. Минимальная финансовая нагрузка для заемщика.
